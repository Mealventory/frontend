# Mealventory Frontend

Cross-platform mobile application for Mealventory — the Smart Grocery Tracker & Meal Planner.

Built with React Native to deliver a seamless iOS experience from a single codebase.

---

## 🚀 Tech Stack

- React Native
- TypeScript
- Firebase Authentication
- (API communication)
- React Navigation

---

## 📱 Core Features

- Secure user authentication (Firebase)
- Smart inventory dashboard
- Camera integration (OCR scanning)
- AI-powered produce recognition
- Recipe recommendations
- Expiry notifications
- Cross-device synchronization
